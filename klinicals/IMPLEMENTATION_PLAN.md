# Klinicals marketing site implementation plan

1. Initialize a Next.js App Router project with TypeScript, Tailwind, and reusable UI foundations.
2. Build the responsive marketing page, product visualizations, conversion sections, pricing, FAQ, and demo request form.
3. Validate demo requests server-side and save them to Supabase using server-only environment variables.
4. Add SEO metadata, sitemap, robots, legal placeholders, and Vercel environment documentation.
5. Review the implementation and report any external credentials needed to activate integrations.
